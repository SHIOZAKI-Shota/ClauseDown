# サンプルリポジトリ

会社・自治体・人の名前は、すべて架空です（houritsuの法令を除く）。

## 使い方

ClauseDown の設定の「Developer」で「サンプルリポジトリを追加」を押し、作る場所のフォルダを選んでください。版の履歴・改定案・施行日・期日を付けた 4 つのリポジトリができ、リポジトリの一覧に加わります。同じ名前のフォルダがあるときは、名前の後ろに（2）などを付けて作ります。

## 中身

| フォルダ | できるリポジトリ | 中身 |
|---|---|---|
| 社内規程 | SAMPLE_見本株式会社_社内規程 | 就業規則。法令式（章・条・項・号、表）。初版と 2026 年の改定、改定案「2027年4月改定」と確認の依頼、届出などの期日 |
| 契約書 | SAMPLE_見本_契約書 | 業務委託契約書・著作権譲渡契約書。契約書式（第1条（目的）、項番号は算用数字）。案と協議後の版、改定案「2027年度の更新」、契約の開始・終了・更新の期日 |
| 条例・要綱 | SAMPLE_見本市_条例・要綱 | 空き家の条例と補助金の交付要綱。漢数字の条番号。要綱の改正、改定案「2027年改正」、パブリックコメント・議会提出・公布の期日 |
| houritsu | SAMPLE_houritsu_法令 | [houritsu](https://github.com/Kohei-Wada/houritsu) の形式の法令 3 件（元号法・国民の祝日に関する法律・消費者契約法）。追加すると、ClauseDown の形に変換するかを聞かれます |

各フォルダの文書は、現行版（最新の版）の内容です。昔の版と改定案の中身は `src/main/samples.ts` に書いてあります。

## 出典

社内規程フォルダの就業規則は、厚生労働省「モデル就業規則」（https://www.mhlw.go.jp/content/001620507.pdf）の規程例をもとに作成しました。会社名・日数・金額などの空欄を埋め、複数の例がある条（労働時間・休日・勤務間インターバル・定年）は 1 つを選んでいます。解説は含めていません。

houritsu フォルダの法令は、houritsu（Kohei-Wada、CC BY 4.0）の Markdown をそのまま使っています。

出典：e-Gov法令検索（https://laws.e-gov.go.jp/）、PDL1.0（https://www.digital.go.jp/resources/open_data/public_data_license_v1.0）。houritsu が e-Gov法令検索の法令データを Markdown に加工して作成
