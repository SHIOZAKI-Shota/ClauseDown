# 見本市空き家改修費補助金交付要綱

### 趣旨
- この要綱は、見本市空き家等の適正管理に関する条例に基づき、空き家の改修に要する費用に対し、予算の範囲内において補助金を交付することについて、見本市補助金等交付規則に定めるもののほか、必要な事項を定める。

### 補助対象者 {#対象者}
- 補助金の交付を受けることができる者は、次の各号のいずれにも該当する者とする。
  - 市の空き家バンクに登録された空き家の所有者等又はその空き家を購入し、若しくは賃借した者
  - 市税を滞納していない者
  - 暴力団員等でない者

### 補助対象経費
- 補助の対象となる経費は、空き家の改修工事に要する費用のうち、次に掲げるものとする。ただし、家財の処分に要する費用を除く。
  - 屋根、外壁その他の外装の改修
  - 台所、浴室、便所その他の水回りの改修
  - 耐震性を高めるための改修

### 補助金の額 {#額}
- 補助金の額は、補助対象経費の2分の1以内の額とし、500,000円を限度とする。
- 前項の額に1,000円未満の端数があるときは、これを切り捨てる。

### 交付の申請
- 補助金の交付を受けようとする者は、改修工事に着手する前に、補助金交付申請書に次に掲げる書類を添えて、市長に提出しなければならない。
  - 改修工事の見積書の写し
  - 改修前の現況写真
  - その他市長が必要と認める書類

### 実績報告
- 補助金の交付の決定を受けた者は、改修工事が完了した日から30日以内又は当該年度の2月末日のいずれか早い日までに、実績報告書を市長に提出しなければならない。

## 附　則 {supplement}
- この要綱は、2026年4月1日から施行する。
- この要綱の改正は、2026年10月1日から施行する。
