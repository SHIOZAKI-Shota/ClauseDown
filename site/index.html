Markdown に条番号は書きません。「###」の並び順から計算し、プレビューに反映します。

主な機能の動き

項目にマウスを重ねると切り替わります。マウスを離しているときは、約 7 秒ごとに次の項目へ進みます。

  1. 比較する2つの版を選択するだけで作成します。番号のみ移動した条は、本文の改正として扱いません。

  2. 改定案で作業し、承認を受けてから現行版に反映します。反映した版には施行日を設定します。

  3. 同じ助詞の連続、ら抜き言葉、法令の用字などを、入力中に波線で示します。

  4. 施行版ごとの有効期間を帯で示し、届出や更新などの期日をタイムラインに並べます。

  5. 版のメッセージに「Closes #2」と書いて現行版に反映すると、課題 #2 が完了します。

保存場所

自分で選んだフォルダに、Markdown のファイルとして保存します。

  • クラウドへの登録は不要です。
  • フォルダは、エクスプローラーや Finder でそのまま扱えます。
  • 版の履歴は、同じフォルダの .git に記録されます。

共有

GitHub・GitLab と同期するかどうかは、リポジトリごとに選択できます。

  • 社内の GitLab にも接続できます。
  • 同期しなければ、文書は PC の外に出ません。
  • 確認依頼は、プルリクエスト・マージリクエストとしても作成されます。

AI

AI を使うかどうかは、設定で選択します。

  • Claude・OpenAI 互換のサービスに接続できます。
  • 手元で動作する Ollama を使えば、文書は PC の外に出ません。
  • 社内のサーバーで動作する Ollama にも接続できます（試験中の機能）。

インストール

配布ファイルには署名がないため、初回だけ OS の警告が表示されます。

Windows

  1. ダウンロードした「ClauseDown-Setup-（版）.exe」を開きます。
  2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を押します。
  3. インストール先を選び、完了したら ClauseDown を起動します。

macOS

  1. ダウンロードした「ClauseDown-（版）-arm64.dmg」を開き、ClauseDown を「アプリケーション」フォルダにドラッグします。
  2. 初回の起動で開けないと表示されたら、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を押します。

よくある質問

ほかの質問や不具合は、GitHub の Issues で受け付けています。

Git の知識は必要ですか？

必要ありません。画面に Git の用語は表示されず、「版の保存」「改定案」「現行版に反映」などの言葉で操作します。

インターネットに接続していなくても使えますか？

使えます。GitHub・GitLab との同期と、外部の AI サービスを使うときだけ、接続が必要です。

Word の文書から始められますか？

Word からの取り込みには対応していません。本文を貼り付け、条の見出しを「###」、項を「-」に直すと、番号は ClauseDown が付けます。Word への出力には対応しています。

文書はどこに保存されますか？

自分で選んだフォルダ（リポジトリ）に、Markdown のファイルとして保存されます。ClauseDown の運営者のサーバーには保存されません。

料金はかかりますか？

かかりません。MIT ライセンスで公開しているオープンソースのアプリです。

Intel の Mac で使えますか？

現在は Apple シリコンの Mac 用の版のみを配布しています。
